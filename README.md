# TP2 Portfolio - Araneo Laureano
Trabajo practico en el cual se realizo un "Portfolio" armado en VSC y bocetado en Figma, con el objetivo de aprender nuevas herramientas (Formularios, grid, @media, galeria o multimedia, etc)
## Información Técnica: 
* Bocetos en Figma y pre armado de la web
* Editor de código: VSC (Visual Studio Code)
* Tamaño de pantalla: 1920x1080 (Desktop) y 600px (Mobil)
